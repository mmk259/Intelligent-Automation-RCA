
# Tests

This directory is intended for automated tests of Intelligent Automation RCA.

Planned test coverage includes:

- Execution-log parsing
- Incident classification
- Knowledge-base validation
- Structured retrieval
- Semantic retrieval
- API endpoint behavior
- LLM integration and error handling
- Verification and report revision

Tests should use synthetic incident examples and mocked external services where appropriate.

Test results should be reproducible and should not depend on access to production systems.
