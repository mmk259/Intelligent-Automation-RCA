
# Dataset

This directory contains data used for development and evaluation of Intelligent Automation RCA.

The project uses UiPath execution-log examples to evaluate incident parsing, classification, knowledge retrieval, and RCA generation.

## Data Handling

Only synthetic, anonymized, or otherwise authorized data should be included in the public repository.

Production logs may contain sensitive operational information, including account identifiers, hostnames, file paths, and process details. Such information must not be committed to the repository.

## Limitations

The current evaluation dataset represents a limited set of incident patterns and should not be considered representative of all UiPath automation failures.
