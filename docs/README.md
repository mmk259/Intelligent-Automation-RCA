## Documentation Conventions

The project distinguishes between:

- **Implemented:** Functionality available in the current codebase.
- **Experimental:** Implemented functionality evaluated as part of the research.
- **Proposed:** Functionality identified for future development but not yet implemented.

Experimental findings should be interpreted within the scope and limitations of the current test set.
